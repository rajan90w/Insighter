# 2D Platformer

A 2D platformer game project built with the Godot game engine. This project is based on the open-source beginner platformer by [GDQuest](https://github.com/gdquest-demos/godot-3-beginner-2d-platformer) and serves as a foundation for gameplay customisation and experimentation.

## 🎮 Overview

The game demonstrates core 2D platforming mechanics, including:

- Player movement and jumping
- Coins and collectible objects
- Enemies and collision detection
- Multiple connected levels
- Title screen, pause menu, and score system

## 🚀 How to Run

1. Install the Godot version compatible with the project you want to run.
2. Open the Godot Project Manager.
3. Import the project by selecting its `project.godot` file from the relevant project folder.
4. Open the project and click **Run Project**.

Use a .NET-enabled Godot 3 editor for the C# / Mono variant.
